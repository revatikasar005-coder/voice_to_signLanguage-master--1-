
# voice_to_signLanguage
Voice to Sign Language Conversion


## Usage

Install dependencies

```
npm install
```

Install Python dependencies and enter the virtual environment

```
pip install pipenv
```
```
pipenv install
```
```
pipenv shell
```

Or, use requirements.txt directly:

```
python -m pip install -r requirements.txt
```

Start the app

```
nodemon server.js
```
